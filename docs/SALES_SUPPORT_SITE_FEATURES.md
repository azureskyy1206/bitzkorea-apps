# Sales Support 사이트 기능 목록

> **제품명:** Sales Support (헤더 표기)  
> **용도:** 영업·견적·발주·변동사항·가격표·세금계산서 매출처 등 내부 영업 지원  
> **문서 기준:** 저장소 내 웹·API 코드 기준으로 정리했습니다. 배포 환경에 따라 일부 API/파일 경로는 다를 수 있습니다.

---

## 1. 계정·인증

| 기능 | 설명 | 경로 / 비고 |
|------|------|----------------|
| 로그인 | 이메일·비밀번호, 세션 쿠키 | `/login` |
| 회원가입 | 신규 계정 요청(관리자 승인 전까지 제한될 수 있음) | `/signup` |
| 로그아웃 | 세션 종료 | 헤더 버튼 → `/api/auth/logout` |
| 마이페이지 | 직함·이름·전화 등 프로필 수정, 비밀번호 변경 | `/me` |
| 세션 확인 | 로그인 여부·역할 등 | `/api/auth/me` (화면에서 사용) |

---

## 2. 권한 구분 (요약)

- **일반 사용자:** 승인된 계정 기준으로 영업 메뉴·대시보드 일부(본인 견적·본인 발주 등) 이용.
- **관리자(`admin`):** 사용자 관리, 발주관리 메뉴, 영업 상단 탭(대시보드·영업변동·영업·발주·채팅) 등 추가 기능.
- **영업 지원 플래그(`can_sales_support`):** 계정별로 관리자가 켜고 끔(견적/영업 관련 권한과 연동될 수 있음).

---

## 3. 글로벌 내비게이션 (로그인 후 헤더)

| 메뉴 | 설명 |
|------|------|
| 대시보드 | `/` — 역할별 요약(아래 4절) |
| 영업변동사항 | `/sales/changes` — 업로드 배치·기간·두 시점 비교 진입 |
| 영업 | `/sales` — 견적·고객·가격표·매출처 등 허브 |
| 발주관리 | `/sales/purchase-orders` — **관리자만** 헤더에 표시 |
| AI 채팅 | `/chat` |
| 사용자 관리 | `/admin/users` — **관리자만** |
| 마이페이지 | `/me` |

모바일: 햄버거 메뉴로 동일 링크 제공.

---

## 4. 대시보드 (`/`)

### 4.1 관리자

- **발주 요청 목록** 조회(검색·필터·상세 모달 등).
- 발주 건별 **상태 확인**, 견적·매입처·세금계산서 매출처 정보·첨부 등 열람.
- (코드 기준) 견적·발주 연동 UI가 중심.

### 4.2 일반 사용자

- **내 견적서** 카드 목록: 생성일, 파일명, 수신처, 벤더, 금액 요약, 발주 상태 배지 등.
- **발주하기** 링크: 조건에 맞는 견적에서 `/sales/orders/new?quote=...` 진입.
- **내 발주 요청** 요약: 접수/반려 등 상태, 반려 사유 표시 등.

---

## 5. 영업 허브 (`/sales`)

| 링크 | 경로 | 기능 요약 |
|------|------|------------|
| 견적서 생성 | `/sales/quote` | V2 견적 화면으로 안내(실제 작성은 Quote V2) |
| 견적서 리스트 | `/sales/quotes` | 팀 견적 목록·다운로드·삭제(권한)·발주·상세·필터/정렬 등 |
| 고객 조회 | `/sales/customers` | 견적 근거에서 추출한 고객 DB 검색, 근거 **미리보기·다운로드**, 고객 삭제 등 |
| 매입처 조회 | `/sales/purchase-vendors` | 주문/엑셀 기반 매입처 적재·검색 |
| 가격표 | `/sales/pricebook` | 벤더별 DB 가격표 조회·단가 편집·제품 추가·검색·저장 |
| 가격표 업로드 | `/sales/pricebook/upload` | 벤더별 가격표 파일 업로드·일괄 반영 |
| 매출 계산서 정보 조회 | `/sales/sales-invoice-rows` | 세금계산서(매출처) 엑셀 적재, 검색·행 추가/수정/삭제 |

---

## 6. 견적서 생성 V2 (`/sales/quote-v2`)

- 견적 **템플릿** 메타 확인, **영업담당** 선택(템플릿 기본 담당 목록).
- **수신처·고객** 검색/선택(고객 DB 연동).
- **벤더·제품** 검색, 품목 행 추가/삭제, 수량·매출단가·매입단가·신규/재계약·비고·제품 노트.
- 로컬 **임시저장(드래프트)** 키로 브라우저에 보관.
- 서버 **견적서 Excel 생성·다운로드**, (환경에 따라) **PDF** 등.
- 생성 후 견적 ID 기반으로 리스트·발주와 연계.

---

## 7. 견적서 리스트 (`/sales/quotes`)

- 목록: 파일명, 수신처, 영업담당, 벤더, 금액, 품목 수, 생성자, **발주/견적 상태** 등.
- **정렬·필터**(상태, 영업담당 등), **검색**.
- 행 확장 시 **견적 메타·품목 표** 확인.
- **Excel / PDF** 다운로드(견적 ID 기준 API).
- **발주하기** 진입(잠금/상태에 따라 비활성 등).
- 관리자: **견적 삭제(소프트)** 등 추가 동작 가능 영역.

---

## 8. 발주하기 (`/sales/orders/new`)

- 쿼리 `quote`로 지정된 견적의 **요약·품목** 확인.
- **라이선스 시작일**, **사용 기간**(1년/영구/기타), 메모.
- 품목별 **매입처** 지정(검색·DB 저장 연동).
- **세금계산서 매출처** 검색·선택, 계산서 담당 **성함·전화·이메일** 입력.
- 첨부 파일 업로드(용량 제한은 서버 정책 따름).
- **발주 요청 등록** → 발주 API(`POST /api/sales/purchase-orders`) 호출 후 견적 리스트 등으로 이동.

---

## 9. 발주관리 (`/sales/purchase-orders`) — 관리자 중심

- 발주 요청 **목록·검색**.
- 건별 **상세**: 견적 연계, 매입처 라인, 세금계산서 매출처, 첨부 다운로드 등.
- **상태 변경**(접수/처리/승인/반려/완료 등 서버 정책에 따름), 반려 시 **사유** 입력.
- 견적 **Excel 다운로드** 등 링크.

---

## 10. 고객 조회 (`/sales/customers`)

- 고객 **검색·페이징** 목록.
- 행 펼침: **최근 견적서 근거** 목록(B4/B6/F4/F6 요약 등).
- 근거별 **미리보기**(시트 일부 표, 컬럼·합계 행 스타일, 마진율·숫자 포맷), **원본 Excel 다운로드**.
- 고객 **삭제**(확인 후 API).

---

## 11. 매입처 조회 (`/sales/purchase-vendors`)

- 매입처 **검색·목록** (엑셀/주문 더미 등에서 적재된 데이터).

---

## 12. 가격표 (`/sales/pricebook` · `/sales/pricebook/upload`)

### 12.1 가격표 관리

- 벤더 목록·연동 배치 메타, **제품 검색**(로컬/서버).
- DB 품목 **매출가·매입가·제품구분** 편집·저장, **신규 품목 추가**.
- **전역 검색**으로 품목 히트 조회 등.

### 12.2 가격표 업로드

- 벤더 선택 후 **파일 업로드**·일괄 반영 플로우.

---

## 13. 매출 계산서 정보 (`/sales/sales-invoice-rows`)

- DB에 적재된 **매출 세금계산서 행** 목록/검색.
- **추가·수정·삭제** (CRUD UI).

---

## 14. 영업변동사항 (`/sales/changes`)

- 업로드된 **배치(영업일·파일명·행 수·상태)** 목록.
- **기간 선택** 후 **기간 리포트** → `/period?from=&to=`.
- 체크박스로 **배치 2개 선택** → **두 시점 변동사항** → `/compare?prev=&curr=`.
- 업로드 화면으로 이동 링크.

---

## 15. 엑셀 업로드 (`/upload`)

- **`.xlsx` 파일** 드래그앤드롭 또는 선택.
- **업로드 + 자동 변동사항** 처리(API).
- 완료 시 결과 JSON 표시, **해당 영업일 리포트**로 이동 버튼.

---

## 16. 일일 변경 리포트 (`/report/[date]`)

- 해당 영업일 **변경 리포트** 표(`ReportTable`).
- **엑셀 다운로드**(서버 생성) 링크: `/api/changes/report/excel?date=...`.
- **AI 요약·질문** 패널(해당 일자 기준 `/api/ai/summary`, `/api/ai/ask`).
- 표: **필터·정렬**, 상단 **합계 행**(이익액 변동·Loss/Drop 합), **엑셀(CSV) 다운로드**(현재 표시 기준).

---

## 17. 두 시점 변동사항 (`/compare`)

- 선택한 이전/현재 배치의 **요약 통계**(추가·삭제·수정·월연기·셀 변경 수 등).
- **동일 `ReportTable`**으로 상세 행 표시·필터·합계·CSV 다운로드.
- 기간 전체 링크: `/changes?from=&to=` (리포트 페이지에서 안내).

---

## 18. 기간별 변경 누적 (`/period`)

- `from`·`to` 쿼리로 **여러 업로드를 누적**한 변동 표.
- `ReportTable` + 합계·CSV 동일 패턴.

---

## 19. 변동사항 전체 (`/changes`)

- `from`·`to` 필수. 기간 누적 데이터 + **두 시점 요약**으로 가는 링크(첫/끝 배치 ID 사용).

---

## 20. AI 채팅 (`/chat`)

- 자연어 **질문** (`POST /api/ai/ask`), 선택적 **기준 날짜**.
- 응답에 **intent·rows** 등 부가 정보 표시 가능.
- 예시 질문 버튼, **대화 초기화**.

---

## 21. 현황판 / 피벗 보기 (`/dashboard`)

- 업로드 **배치** 선택 → 시트 목록 로드 → **시트별 표 데이터** 조회(`GET /api/dashboard...`).
- 숫자·비율 포맷 등 단순 그리드 뷰.

---

## 22. 사용자 관리 (`/admin/users`) — 관리자

- 사용자 **목록** (이메일, 직함·이름, 승인 상태, 역할, 영업권한, 가입일).
- **승인 / 거절**, **관리자 지정·해제**, **영업권한 토글**.

---

## 23. API·다운로드 (사용자 관점에서 자주 쓰는 것)

웹이 호출하는 대표 API(일부):

- 인증: `/api/auth/login`, `/api/auth/logout`, `/api/auth/me`, `/api/auth/password`, 회원가입 관련
- 배치: `/api/batches`, 업로드 `/api/upload`
- 변동·리포트: `/api/changes/report`, `/api/changes/report/excel`, `/api/changes/period`, `/api/compare`
- 대시보드 스냅샷: `/api/dashboard`, `/api/dashboard/sheets`
- 견적: `/api/sales/quotes`, `/api/sales/quotes/{id}/...`, 견적 생성·다운로드·PDF 등
- 발주: `/api/sales/purchase-orders` (POST 목록·PATCH 등)
- 고객·근거: `/api/sales/customers`, `quote-sources` **preview / download**
- 가격표·벤더·제품 검색, 매입처, 세금계산서 행 CRUD
- AI: `/api/ai/ask`, `/api/ai/summary`
- 관리자: `/api/admin/users`, `/api/admin/users/{id}`

## 24. Word(.docx)로 받는 방법

1. 이 파일 `docs/SALES_SUPPORT_SITE_FEATURES.md` 을 로컬에서 연 뒤  
2. **Microsoft Word**에서 `파일` → `열기`로 `.md`를 열거나, 내용을 복사해 Word에 붙여넣기  
3. `다른 이름으로 저장`에서 **형식: Word 문서(.docx)** 선택  

또는 **Pandoc** 등으로 변환:  
`pandoc docs/SALES_SUPPORT_SITE_FEATURES.md -o SITE_FEATURES.docx`
