## 1. 서비스 개요

Adobe 학교 포털은 **공동구매 Adobe 라이선스**에 참여한 학교가, 할당받은 **좌석 수(Quota)** 안에서 **사용자 이메일(계정)** 을 등록·관리하는 서비스입니다.

| 용어 | 설명 |
|------|------|
| **좌석(Quota)** | 학교·담당자·계약 차수별로 부여된 라이선스 수 (`사용 중 / 전체`) |
| **계정** | Adobe에 등록할 사용자 이메일 |
| **계약 차수** | 예: `CY25-H2`(2025 하반기), `CY26-H1`(2026 상반기) |
| **담당자(Contact)** | 학교 내 라이선스 담당자 (상·하반기 담당이 다를 수 있음) |

> 이 포털에는 **견적(Quote)** 기능이 없습니다. 좌석 할당·이메일 등록이 핵심입니다.

## 2. 로그인·담당자 선택

### 2.1 로그인

1. https://adobe.bitzkorea.com/login 접속
2. 관리자가 안내 메일로 전달한 **6자리 접속 코드** 입력
3. 로그인 실패가 반복되면 **15분간 잠금**될 수 있습니다

### 2.2 담당자 선택

학교에 **담당자가 2명 이상**이면 첫 로그인 후 담당자 선택 화면이 나옵니다.

| URL | 용도 |
|-----|------|
| `/select-contact` | 최초 선택 |
| `/select-contact?switch=1` | 담당자 변경 |

- 담당자 카드에 **차수별 좌석** `사용/전체` 표시
- **할당 좌석이 0**인 담당자·차수는 선택 불가

담당자가 **1명**이면 자동 선택 후 대시보드로 이동합니다.  
담당자가 **0명**이면 학교 전체 범위로 동작합니다.

### 2.3 로그아웃

상단·모바일 메뉴 **로그아웃** — 다시 사용 시 접속 코드 입력

## 3. 계정 관리 (대시보드)

**URL:** `/dashboard`

### 3.1 화면 구성

- **학교 정보:** 학교명, 사업자번호
- **현재 담당자** 이름
- **라이선스 사용량:** 진행 바 `사용 중 / 전체 좌석`
- **계약 차수 탭:** 여러 차수가 있으면 탭으로 전환

### 3.2 계정 목록

| 상태 | 의미 |
|------|------|
| pending | Adobe 동기화 대기 중 |
| active | 사용 중(등록 완료) |
| failed | 동기화 실패 — 관리자 문의 |
| removed | 삭제됨 |

- **이메일 검색:** 2글자 이상 또는 `@` 포함 시 검색
- 목록은 **15초마다** 자동 새로고침 (pending 있으면 5초)

### 3.3 계정 추가

**단건**

1. 이메일 입력 → 추가
2. 좌석 여유가 있어야 함

**일괄**

1. 여러 이메일을 붙여넣기 (줄바꿈·쉼표·세미콜론 자동 구분)
2. 추가 → pending 상태로 Adobe 동기화 큐에 등록

### 3.4 계정 수정·삭제

| 작업 | 설명 |
|------|------|
| **이메일 수정** | 모달에서 변경 (Adobe 재동기화) |
| **삭제** | 단건 또는 체크 후 일괄 삭제 |

삭제·추가는 **감사 로그**에 기록됩니다.

### 3.5 엑셀 다운로드

- **할당 계정 목록** Excel 다운로드 (`/accounts/export`)
- 현재 담당자·선택한 계약 차수 기준

## 4. 감사 로그

**URL:** `/audit`

본인 학교에서 발생한 변경 이력만 조회합니다.

| 항목 | 예시 |
|------|------|
| 작업 | account.create / update / remove |
| 결과 | queued(대기) / success / failed |
| 시각·대상 이메일 | |

Adobe 쪽 반영이 끝나기 전에는 **queued**로 표시됩니다.

## 5. 라이선스 기간(계약 차수)

### 5.1 차수 전환

대시보드 상단 **탭**으로 `CY25-H2`, `CY26-H1` 등을 전환합니다.  
브라우저에 선택이 저장되어 다음 방문 시에도 유지됩니다.

### 5.2 좌석 초과

`사용 중 >= 전체`이면 **추가 등록 불가** — 관리자에게 좌석 증설·재배정 요청

### 5.3 담당자별 좌석

같은 학교라도 **담당자마다** 차수별 좌석이 다를 수 있습니다.  
반드시 **본인 담당자**로 로그인했는지 확인하세요 (메뉴 → 담당자 변경).

## 6. 자주 묻는 질문

**Q. 접속 코드를 잃어버렸습니다.**  
A. Adobe 포털 **관리자**에게 재발급을 요청하세요. (관리자: 학교 상세 → 접속 코드 재발급)

**Q. 계정이 pending에서 안 바뀝니다.**  
A. Adobe 동기화 큐 처리 중입니다. 수 분~수십 분 걸릴 수 있습니다. 오래 지속되면 관리자에게 문의.

**Q. failed 상태입니다.**  
A. 이메일 형식·Adobe 측 정책·중복 등 원인이 있습니다. 감사 로그와 함께 관리자에게 전달하세요.

**Q. 상반기/하반기 담당이 다른데 계정이 안 보입니다.**  
A. **담당자 변경** 메뉴에서 올바른 담당자를 선택했는지, 해당 차수 탭이 맞는지 확인하세요.

**Q. 관리자 화면이 필요합니다.**  
A. 학교 사용자는 `/admin`에 접근할 수 없습니다. [관리자 가이드](./GUIDE_ADMIN.md)는 운영 담당자용입니다.
