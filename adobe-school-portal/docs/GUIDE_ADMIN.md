## 1. 관리자 접속

### 1.1 로그인

1. https://adobe.bitzkorea.com/admin/login
2. 관리자 **비밀번호** 입력
3. 실패 반복 시 **15분 잠금**

학교 포털(`/login`) 하단 링크로도 관리자 로그인에 접근할 수 있습니다.

### 1.2 세션

- `admin_session` 쿠키 기반
- API는 `/api/admin/*` 프록시 경유
- **로그아웃:** 상단 메뉴

### 1.3 학교 포털로 전환

관리자 메뉴 **「학교 포털」** → `/login` (6자리 코드로 학교 화면 테스트 가능)

## 4. 이메일 조회

**URL:** `/admin/accounts`  
**검색:** `/admin/accounts?q={email}`

- **전체 학교·차수**에서 이메일 검색 (2글자 이상)
- 상태, 학교명, 사업자번호, 차수, 좌석 사용량
- **이름 변경 이력** (renamed-from)
- 학교 상세·필터된 감사 로그로 이동

**용도:** 특정 교사/직원 이메일이 어느 학교에 등록됐는지 빠르게 확인

## 5. 학교 관리

**URL:** `/admin/schools`

### 5.1 목록

- 페이지당 30건, **담당자(contact) 단위** 행
- **검색:** 학교명·사업자번호
- **필터:** 계약 차수, 할당/미할당, SDL 전용 / Named 전용

### 5.2 컬럼 요약

- 학교명, 사업자번호, SDL 뱃지
- 담당자 연락처
- 차수별 할당 현황
- 할당 상태, 합계

### 5.3 일괄 로그인 안내 메일

1. 이메일이 있는 담당자 **체크**
2. **로그인 안내 메일 발송**
3. 템플릿은 [메일 양식](#9-메일-양식)에서 편집

### 5.4 학교 상세

행 클릭 → `/admin/schools/{id}`

## 6. 학교 상세 — 접속·계정

**URL:** `/admin/schools/{id}`

### 6.1 접속·담당자 (Access)

| 기능 | 설명 |
|------|------|
| **접속 코드 발급** | 6자리 코드 생성·표시 |
| **재발급** | 기존 코드 무효화 후 새 코드 |
| **폐기** | 코드 사용 불가 |
| **학교 대표 이메일** | 수정 |
| **담당자** | 이름·전화·이메일 CRUD |
| **로그인 안내 메일** | 선택 담당자에게 발송 |

### 6.2 계정 관리 (Accounts)

학교 사용자 대시보드와 **동일 CRUD**이나 **모든 담당자·차수** 선택 가능:

- 차수·담당자 선택
- 단건/일괄 추가, 수정, 일괄 삭제
- 좌석 사용량 바, 이메일 검색

### 6.3 라이선스 요약

차수별 **등록 수 vs 할당 수** 개요

## 7. 엑셀 입·출력

**URL:** `/admin/import`

### 7.1 가져오기 (Import)

| 유형 | 설명 |
|------|------|
| **학교 + 좌석 (마스터)** | 학교·담당·좌석 마스터 ± Named 메일 |
| **Named 메일만** | 기존 학교에 계정만 추가 |

**옵션**

- Named 계정을 **active**로 즉시 반영
- 접속 코드 일괄 발급 (서버 CSV 저장)

### 7.2 템플릿 다운로드

- 마스터 목록
- Named 메일
- 사용 계정(usage) 형식

### 7.3보내기 (Export)

- **사용 계정** Excel — 전체 차수 또는 차수별

**운영 순서 (신규 차수):**

1. 마스터 Excel로 학교·좌석 적재
2. Named 메일 import (필요 시)
3. 대시보드 KPI·학교 목록 검증
4. 담당자에게 접속 코드·안내 메일

## 10. 감사 로그

**URL:** `/admin/audit`  
**필터:** `/admin/audit?school_id={id}&q={email}`

- **전체 학교** 변경 이력 (페이지당 50건)
- 필터: 학교 ID, 작업 유형, 이메일
- Adobe 동기화 결과·행위자 표시

학교 사용자 `/audit`은 **본인 학교만** — 관리자는 **전역** 조회

## 11. 대사(Reconcile) — 숨김 메뉴

**URL:** `/admin/reconcile` (네비게이션 미포함)

Named Excel · 포털 DB · Adobe UMAPI **3자 대사** 도구

| 모드 | 설명 |
|------|------|
| Excel + Adobe | 파일·Adobe·DB 비교 |
| Adobe ↔ Portal | DB와 Adobe만 |

**불일치 표**

- Adobe에만 있음
- 포털에만 있음
- Excel 불일치
- 미등록 학교

**용도:** 대량 import 후 검증, 장애 조사

## 12. 운영 체크리스트

### 매일

- [ ] `/admin` — failed 동기화·pending 과다 여부
- [ ] 이메일 조회로 신규 이슈 계정 확인

### 차수 오픈 시

- [ ] Import — 마스터·Named
- [ ] KPI·Top 학교 숫자 검증
- [ ] 접속 코드 발급·안내 메일
- [ ] (선택) Reconcile 실행

### 장애 대응

| 증상 | 조치 |
|------|------|
| 계정 failed 다수 | 감사 로그·Adobe 큐 확인, Reconcile |
| 좌석 초과 신고 | 학교 상세에서 quota·할당 확인 |
| 로그인 코드 분실 | 학교 상세 → 재발급 |
| 메일 미발송 | email-templates·SMTP 설정 |

### API 전용 (UI 없음)

다음은 백엔드 API로만 가능합니다 (필요 시 개발·스크립트):

- `setQuota` — 수동 좌석 배정
- `createSchool` — 학교 수동 생성
- `issueMissingTokens` / `issueAllTokens` — 토큰 일괄 발급
